# Medhayate — मेधायते

*Sanskrit: "sharpens one's own intellect"*

An offline Android brain-games app: five thinking games, each with hints that explain
their reasoning, behind a deliberate 15-minutes-per-4-hours play limit.

**No account, no internet, no ads, no permissions at all.**

## About this site

This site exists to host the app's privacy policy and terms at a public address, as
the Google Play listing requires. The same documents ship inside the app itself and
can be read offline from the library screen — the app has no network access, so it
never fetches this page.

The application's source code is not published here and is not open source.
